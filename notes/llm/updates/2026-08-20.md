## 资料快照

### FlashAttention-4

论文：[FlashAttention-4: Algorithm and Kernel Pipelining Co-Design for Asymmetric Hardware Scaling](https://arxiv.org/abs/2603.05451)。核心不是重新定义 attention，而是针对 Blackwell 的硬件不对称：Tensor Core 增长快于 shared-memory / exp 等非矩阵单元，因此使用异步 MMA、更大 tile、软件近似指数/softmax rescaling、2-CTA MMA 和 Tensor Memory 降低非 MMA 开销。论文还展示了 CuTe-DSL 实现，说明后续“高性能 CUDA”会越来越靠近 Python 驱动的 DSL，而不是只靠大型 C++ 模板。

### DeepSeek-V3.2 / DSA

论文：[DeepSeek-V3.2](https://arxiv.org/abs/2512.02556)。DSA 的学习价值在于：把“完整 attention 的 IO/计算开销”转化为 indexer + 稀疏 token 选择问题。先掌握 MLA 和 FA2，再看 DSA 的 indexer、top-k 选择及其对 prefill/decode 的影响。

### SageAttention3 / Kascade

- [SageAttention3](https://arxiv.org/abs/2505.11594)：面向 Blackwell FP4 Tensor Core 的 attention，同时探索训练态 8-bit attention；要重点区分 inference-only 低比特和训练收敛问题。
- [Kascade](https://arxiv.org/abs/2512.16391)：训练无关的跨层稀疏 attention，通过 anchor layer 计算 top-k 并在相邻层复用，适合挂在 DSA 后理解“稀疏选择如何落到 serving”。

### DeepSeek-V4

官方入口：[模型集合](https://huggingface.co/collections/deepseek-ai/deepseek-v4) 和 [V4-Pro 技术报告](https://huggingface.co/deepseek-ai/DeepSeek-V4-Pro/blob/main/DeepSeek_V4.pdf)。当前仓库把 V4 作为 V3.2 的增量学习，不切换主线：先用 V3.2 建立完整基线，再比较 CSA/HCA、mHC/Muon、MXFP4 和 1M context 下的 KV/FLOPs 账。第三方转载或社区仓库只作为线索，不能作为模型结构和性能数字的唯一来源。

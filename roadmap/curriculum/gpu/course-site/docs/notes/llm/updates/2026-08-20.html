2026-08-20：学习计划与最新资料更新#

计划结论#

  • 算子主线已经切到 Triton B1：Vector Add → MatMul → Fused Softmax → Flash Attention → GQA/Fused MLP。
  • 每个任务固定走：看完原理 → 直接去 LeetGPU 题目编辑器写题并通过 → 同步本地 → 真实 GPU benchmark → profiler；LeetGPU 未通过时不进入真实卡。
  • CUDA 纯 kernel 练习后置，不再为了“补齐 CUDA”打断 Triton 主线；只在 Triton 代码需要解释底层行为时回看 CUDA。
  • 理论主线继续按 DeepSeek-V3.2 → V4 推进：先完成 V3.2 config + 手算，再进入 FA2 → MLA → DSA，随后看 V4 的 CSA/HCA、mHC/Muon、MXFP4。

资料快照#

FlashAttention-4#

论文：FlashAttention-4: Algorithm and Kernel Pipelining Co-Design for Asymmetric Hardware Scaling。核心不是重新定义 attention，而是针对 Blackwell 的硬件不对称：Tensor Core 增长快于 shared-memory / exp 等非矩阵单元，因此使用异步 MMA、更大 tile、软件近似指数/softmax rescaling、2-CTA MMA 和 Tensor Memory 降低非 MMA 开销。论文还展示了 CuTe-DSL 实现，说明后续“高性能 CUDA”会越来越靠近 Python 驱动的 DSL，而不是只靠大型 C++ 模板。

DeepSeek-V3.2 / DSA#

论文：DeepSeek-V3.2。DSA 的学习价值在于：把“完整 attention 的 IO/计算开销”转化为 indexer + 稀疏 token 选择问题。先掌握 MLA 和 FA2，再看 DSA 的 indexer、top-k 选择及其对 prefill/decode 的影响。

SageAttention3 / Kascade#

  • SageAttention3：面向 Blackwell FP4 Tensor Core 的 attention，同时探索训练态 8-bit attention；要重点区分 inference-only 低比特和训练收敛问题。
  • Kascade：训练无关的跨层稀疏 attention，通过 anchor layer 计算 top-k 并在相邻层复用，适合挂在 DSA 后理解“稀疏选择如何落到 serving”。

DeepSeek-V4#

官方入口：模型集合 和 V4-Pro 技术报告。当前仓库把 V4 作为 V3.2 的增量学习，不切换主线：先用 V3.2 建立完整基线，再比较 CSA/HCA、mHC/Muon、MXFP4 和 1M context 下的 KV/FLOPs 账。第三方转载或社区仓库只作为线索，不能作为模型结构和性能数字的唯一来源。

对当前学习的直接影响#

  1. 现在先写 Triton Vector Add，不提前读 FA4 实现细节。
  2. B1 完成后写 Triton MatMul；先在 LeetGPU 完成接口和正确性闭环，再上真实 GPU 做性能记录。
  3. B2/B3 进入 Fused Softmax / Flash Attention 时，再把 FA2、DSA 和 FA4 的差异挂到对应实现点。
  4. CUDA softmax 的 warp shuffle、手写 FlashAttention 留作后置深钻，不作为当前阻塞项。

卡点 / 怎么解决的#

  1. LeetGPU GEMM fp16 tiled K=16：K 维太小（只有16），shared memory tiling 的加速比无法体现——naive 和 tiled 的 GFLOPS 几乎一样，因为 K=16 时 naive 的复用率已经够高了。需要本地 4090 上跑大 K（如 1024+）才能看到显著加速。解法：正确性验证通过即可，性能测试标记为待做。

  2. 仓库混乱：两套计划（README + MAIN）打架、参考代码和我的代码混在一起、进度散在五处。解法：彻底重组——PATH 唯一进度源，NOW 当前焦点，reference/solutions 分离，roadmap 收未来阶段。

  3. 理论线是空的：notes/algorithms/ 只有一个 README。解法：4 条基础笔记（online softmax / parallel reduce / flash attention 机制 / 量化基础）+ 4 条高阶笔记（MoE / SpecDecode / PD分离 / MLA）。

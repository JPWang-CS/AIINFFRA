# 盘古部署教程维护规则

本模块采用“先讨论当前步骤，再执行，再整理教程”的顺序。已确认的步骤和授权不重复询问；新增拓扑、版本、设备分配或公共范围变化时先讨论。

- 每次完成部署、定位问题或修正命令，同时更新实操教程、关键操作代码、注意事项和日期记录。该要求持续到 92B PD 混部、PD 分离、两阶段分析与调试总结完成。
- 教程主文为 D:/Desktop/Code/Learn/AIINFFRA/practice/pangu-92b/tutorial.md；项目副本为 D:/Desktop/Code/CC4Ascend/projects/pangu-92b整网分析/tutorial.md。两份正文保持字节一致。
- 教程按操作顺序书写，包含运行位置、前置条件、完整命令、参数解释、预期结果、结果检查、正常退出和故障处理。正文使用书面中文，不写协作过程、宣传句或完成口号。
- 已验证步骤采用成功运行的实际版本。新编写的复现辅助代码须说明本地检查与真机复验的范围；不把静态检查记为模型或通信实测。
- 原始运行记录和失败日志保留。复跑使用新 run_id、新 nonce 和独立目录，不能覆盖旧证据。更新教程不改动原始证据以满足检查。
- 源码映射、更新日期和检查范围保存到项目 tutorial-maintenance.md，执行证据继续按日期归档。
- 远端优先使用已配置目标连接；在自有容器及已经确认的个人目录执行。当前阶段为两台已确认的小模型节点。其他节点和 92B 拓扑按后续讨论确定。
- CANN 显式加载个人版本，远端操作不修改公共 CANN、宿主机、设备 TLS 或网络配置。退出时按既定约定处理当前会话历史。
- 教程更新不自动推进 PATH.md / NOW.md 的学习进度，不写全局 memory，不创建无人值守任务。
